# 资料目录

所有 JSON Lines 文件使用 UTF-8 编码。data/catalog.json 保存字段、行数、主键及校验和；原始资料不含分析结果。

## missions

文件 data/missions.jsonl；120 条；主键 mission_id。字段：mission_id, kind, weather_bucket, coverage_class, started_at, status。

## legs

文件 data/legs.jsonl；240 条；主键 leg_id。字段：leg_id, mission_id, route_segment, vehicle, handoff_to, start, end。

## telemetry

文件 data/telemetry.jsonl；600 条；主键 telemetry_id。字段：telemetry_id, leg_id, quality, link_margin, occurred_at, received_at。

## delivery_receipts

文件 data/delivery_receipts.jsonl；100 条；主键 receipt_id。字段：receipt_id, mission_id, accepted, received_at。

## reserve_assets

文件 data/reserve_assets.jsonl；10 条；主键 asset_id。字段：asset_id, kind, available_from, available_to。

## route_policy

文件 data/route_policy.jsonl；2 条；主键 policy_id。字段：policy_id, mission_kind, minimum_observed_missions, minimum_completion_lower, safety_buffer_minutes。

## confirmed_missions

文件 data/confirmed_missions.jsonl；1 条；主键 confirm_id。字段：confirm_id, request_id, asset_id, start, end, cancelled_at。

## requests

文件 data/requests.jsonl；12 条；主键 request_id。字段：request_id, kind, weather_bucket, coverage_class, start, end, asset_kind。

## corrections

文件 data/corrections.jsonl；1 条；主键 correction_id。字段：correction_id, telemetry_id, issued_at, new_quality。
