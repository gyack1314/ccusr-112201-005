# 业务约定

mission_id 是履约单位，leg_id 为路线分段，handoff_to 表示接续；仅 delivery_receipts.accepted=true 证明交付。telemetry.quality=missing 为未知。weather_bucket 与 coverage_class 是预定义比较条件，未覆盖条件不可自动推断合格。reserve_assets 中每个 asset 同时仅服务一个已确认 [start,end) 任务；confirmed_missions 保留占用，撤销须明确 cancel。

route_policy 的 minimum_observed_missions 是适用任务类型及条件下有完整结局的历史任务下限，minimum_completion_lower 指保守完成率下界；safety_buffer_minutes 在资源开始和结束两侧均保留。

所有记录为本地合成资料；缺失值为 JSON null。资料中的候选操作不是已确认操作。编号仅标识对象，不携带优先级。历史截点以当时已获知事实判断，不以后来的更正冒充当时已知。
